## Project Description
This repository contains a Python implementation of a Genetic Algorithm designed to optimize the flight path of Unmanned Aerial Vehicles (UAVs) in a disaster management scenario. The algorithm finds an optimal trajectory across a 50x50 grid that minimizes energy consumption while strictly avoiding environmental hazard zones.

## How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run the environment map: `python uav_env.py`
3. Run the Genetic Algorithm and view graphs: `python ga_solver.py`
